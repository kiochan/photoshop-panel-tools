# Security policy

This project is an experimental trial. No runtime compatibility or security certification is claimed.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/kiochan/photoshop-panel-tools/security/advisories/new). If that feature is unavailable, open an issue requesting a private reporting channel without disclosing exploit details, secrets or private documents.

Do not post local settings, window recovery records, process paths, artwork, credentials or third-party plugin code. Include the affected version, platform and a minimal sanitized description.

Only the latest dev/prod builds are maintained. Verify the SHA256 for downloaded packages. Unsigned trial binaries may be subject to operating-system checks. Publication credentials are restricted to the upstream workflow and the Panel Tools receiver; pull requests and forks must never use those credentials.
